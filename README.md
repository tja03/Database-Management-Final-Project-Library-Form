# Database-Management-Final-Project-Library-Form
Personal Library System created for a final DBMS class

This Access database was for a Graduate Level class (Database Management), all information that surrounds names and addresses are part of a fictious manner. Any resemblance to to actual persons, living or dead, is purely conicidental.

The project itself dives into a personal library collection system that can be re-worked towards a real business, as it tracks and details who has loaned what item. There is a minimal amount of information within this project but it is enough for insights to be made.

A form has also been created so that most interactions can be done through the UI.
